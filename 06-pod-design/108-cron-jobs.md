# Cron Jobs

Is a job that can be scheduled, just like `crontab` in linux

```yaml
apiVersion: batch/v1
kind: CronJob
metadata:
  name: reporting-cron-job
spec:
  schedule: "*/1 * * * *"
  jobTemplate:
    spec:
      completions: 3
      parallelism: 3
      template:
        spec:
          containers:
            - name: reporting-tool
              image: reporting-tool:latest
          restartPolicy: Never
```

Cron Expression Format

```
# ┌───────────── minute (0 - 59)
# │ ┌───────────── hour (0 - 23)
# │ │ ┌───────────── day of the month (1 - 31)
# │ │ │ ┌───────────── month (1 - 12)
# │ │ │ │ ┌───────────── day of the week (0 - 6) (Sunday to Saturday;
# │ │ │ │ │                                   7 is also Sunday on some systems)
# │ │ │ │ │
# │ │ │ │ │
# * * * * * command to execute
```

To run it:

```bash
$ kubectl create -f cron-job-definition.yaml
$ kubectl get cronjob

NAME                 SCHEDULE      SUSPEND   ACTIVE
reporting-cron-job   */1 * * * *   False     0
```
